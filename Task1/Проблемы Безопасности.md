# 1. Хранение данных
- Cистема хранения разрознена (Excel, PDF, 1C, Файловый сервер), нет единого источника истины
- Нет шифрования дисков и баз данных
- Рукописные записи и ксерокопии хранятся в открытом виде
- Отсутствуют резервные копии данных

# 2. Отсутствие контроля доступа
- Отсутствуют роли и права доступа к данным 
- Сотрудники видят больше информации, чем им нужно (принцип минимальных привилегий нарушен).
- Из локальной сети можно получить доступ к важным системам и данных

# 3. Несоответствие ФЗ-152
- Нет политики обработки ПДн
- Нет реестра операций
- Нет механизмов отзыва согласия
- Особо защищаемые данные (результаты анализов и диагнозы) не изолированы

# 4. Риски утечки
- IT-администратор имеет полный доступ
- Нет DLP, можно скачивать данные и передавать любые данные 
- Нет мониторинга аномального поведения

# 5. Отсутствие автоматизации и аудита
- Нет логирования действий сотрудников
- Анализы и дианозы могут изменяться, отсутствует версионность таких данных. Текущая система не поддерживает версионность, либо подвержена ошибкам из-за ручной обработки.

# 6. Подготовка к росту
- Архитектура не масштабируется
- Компания не имеет возможности интегрировать API, т.к. большиство информации обрабатывается вручную
- Физические носители усложнят взаимодействие между филиалами, транспортировка или ксерокопирование сильно замедлят процесс и может ухудшить качество самих данных
