# Автоматизированные контроли (At Rest / In Transit)

## At Rest
- Шифрование томов/объектов: KMS/Vault, ротация ключей, запрет слабых алгоритмов.
- Политики доступа по тегам (ABAC): PDP/OPA, проверка на уровне приложений и хранилищ.
- Аудит доступа/изменений: централизованный сбор (SIEM), алерты на аномалии.
- Версионирование и WORM‑политики для критичных документов.
- DLP для файловых хранилищ и в момент загрузок.
- Политики сроков хранения и авто‑удаления (Lifecycle Management).

## In Transit
- TLS 1.2+/mTLS между сервисами и внешними системами (лаборатория, 1С).
- Подпись/хэш целостности для обменных файлов/сообщений.
- Контракты API с минимизацией полей, валидация схем.
- Transport Rules/DLP для почты: блок/карантин/шифрование вложений.
- Rate limiting/анти‑скрейпинг на API Gateway, защита от повторов.
